INVISUAL — update #43 (Blog tanpa hero + editor admin lengkap + unggah gambar
langsung ke Cloudinary dari editor)

APA INI
A) HALAMAN /blog
- Area hero besar ("BLOG / Notes on design & behind the project…") DIHAPUS.
  Halaman langsung menampilkan filter kategori dan daftar artikel.
- Artikel yang dicentang "Artikel unggulan" tampil sebagai kartu besar
  melintang di paling atas (gambar kiri, judul + ringkasan kanan).
- Judul H1 tetap ada tapi tersembunyi (khusus mesin pencari & pembaca layar),
  jadi SEO tidak berubah.

B) GAMBAR LANGSUNG KE CLOUDINARY (tanpa salin URL lagi)
- Gambar sampul: klik kotak "Klik atau seret gambar ke sini" -> pilih file
  dari komputer -> otomatis terunggah ke Cloudinary (folder "blog/") ->
  URL terisi sendiri -> pratinjau langsung tampil. Ada tombol Ganti / Hapus.
  Masih bisa "Tempel URL manual" kalau perlu.
- Gambar di dalam artikel, tiga cara, semuanya otomatis:
    1) tombol gambar (ikon foto, warna aksen) di toolbar -> pilih file;
    2) SERET file gambar dari komputer langsung ke kotak tulisan;
    3) TEMPEL (Ctrl+V) gambar dari clipboard (mis. hasil screenshot).
  Saat diunggah muncul teks "![Mengunggah nama-file…]()" lalu otomatis berubah
  jadi "![teks alt](https://res.cloudinary.com/...)" dan teks alt-nya langsung
  terseleksi supaya tinggal diketik ulang.
- Gambar besar diperkecil otomatis di browser (sisi terpanjang maks 2400 px)
  sebelum dikirim, dan URL hasilnya memakai f_auto,q_auto (WebP/AVIF otomatis).
- "Galeri gambar" (ikon galeri di toolbar): menampilkan gambar yang sudah ada
  di folder blog/ Cloudinary. Arahkan kursor ke gambar -> "Sisipkan" (ke isi)
  atau "Sampul".
- Unggahan berjalan LANGSUNG browser -> Cloudinary (server kita hanya memberi
  tanda tangan keamanan), jadi tidak kena batas ukuran body Vercel.

C) EDITOR ADMIN JAUH LEBIH LENGKAP
- Toolbar baru: blok kode, garis pembatas, tabel, selain H2/H3/tebal/miring/
  tautan/daftar/kutipan. Pintasan: Ctrl+B tebal, Ctrl+I miring, Ctrl+S simpan.
- Mode "Fokus" (layar penuh, Esc untuk keluar) dan Pratinjau yang tampilannya
  PERSIS sama dengan halaman publik.
- "Buat otomatis dari isi" untuk ringkasan/meta description (potong di akhir
  kalimat, 70–160 karakter). Penghitung karakter di judul, ringkasan, judul
  Google.
- Slug dicek otomatis saat mengetik: "tersedia" / "sudah dipakai".
- Checklist SEO 11 poin + progress bar (judul, meta, slug, sampul+alt,
  sub-judul, >=300 kata, gambar isi + alt, tautan, kategori, >=2 tag).
- Pratinjau "Tampilan di Google" (hasil pencarian) dan "Kartu saat dibagikan"
  (WhatsApp/LinkedIn/Facebook) — live saat mengetik.
- "Kerangka artikel": daftar sub-judul, klik untuk lompat ke bagian itu.
- JADWALKAN TERBIT: klik "Atur tanggal / jadwalkan terbit", pilih tanggal+jam
  (WIB). Kalau tanggalnya di masa depan, tombol utama berubah jadi
  "Jadwalkan". Artikel otomatis tayang pada waktu itu (halaman publik hanya
  menampilkan artikel yang sudah lewat waktunya) dan dikirim ke mesin pencari
  saat tayang (dipicu saat Anda membuka /admin/blog setelah waktunya lewat;
  sitemap.xml juga memuatnya otomatis).
- Perubahan belum tersimpan: ada peringatan kalau tab ditutup, plus cadangan
  otomatis di browser — kalau tab tertutup tak sengaja, saat dibuka lagi
  muncul tombol "Pulihkan".
- Setelah artikel baru disimpan, Anda TETAP di editor (tidak dilempar ke
  daftar). Ada tautan "Pratinjau halaman penuh" dan "Buka artikel di situs".
- Pratinjau draf: /admin/blog/<id>/preview — tampilan publik lengkap dengan
  pita kuning "Pratinjau admin". Draf TIDAK bisa dilihat pengunjung.

D) DAFTAR ARTIKEL ADMIN
- Filter baru "Terjadwal" (+ jumlah di tiap filter), badge Terjadwal,
  tombol "Pratinjau" untuk draf/terjadwal, "Terbitkan sekarang" untuk artikel
  terjadwal, dan "Duplikat" (membuat salinan sebagai draf lalu membukanya).

E) LAIN-LAIN
- Gambar share (og:image) sekarang selalu JPG 1200x630 walau URL sampul sudah
  memakai f_auto (aman untuk semua platform).

================================================================
TIDAK ADA SQL BARU. Tidak perlu npm install baru.

LANGKAH 1 — Ambil API key Cloudinary (sekali, 2 menit)
  a) Masuk https://console.cloudinary.com (akun cloud "akrkmnd").
  b) Menu kiri: Settings (ikon gerigi) -> API Keys
     (di tampilan lama: Dashboard -> bagian "Product Environment Credentials").
  c) Catat:  API Key  (angka ~15 digit)  dan  API Secret  (klik ikon mata /
     "Reveal" untuk melihat). JANGAN bagikan API Secret ke siapa pun.

LANGKAH 2 — Isi di Vercel
  Vercel -> project invisual -> Settings -> Environment Variables -> Add:
     CLOUDINARY_CLOUD_NAME = akrkmnd
     CLOUDINARY_API_KEY    = <API Key dari langkah 1>
     CLOUDINARY_API_SECRET = <API Secret dari langkah 1>
  Centang Production (dan Preview kalau mau). Save.
  (Untuk coba di lokal: tambahkan 3 baris yang sama ke file .env.local.)

LANGKAH 3 — Pasang file (di FOLDER ROOT proyek)
  unzip -o ~/Downloads/invisual-update-43.zip
  rm -rf .next node_modules/.cache
  npm run dev        <-- cek lokal: /blog dan /admin/blog/new

LANGKAH 4 — Deploy
  git add -A
  git commit -m "feat: blog tanpa hero, editor admin lengkap, unggah Cloudinary langsung"
  git push
  Vercel otomatis build. Kalau variabel Cloudinary baru ditambahkan SETELAH
  build terakhir, lakukan Redeploy sekali (Deployments -> ... -> Redeploy)
  supaya variabelnya terbaca.

CEK CEPAT SETELAH DEPLOY
  1) Buka /blog -> hero sudah hilang, artikel unggulan tampil besar di atas.
  2) /admin/blog/new -> kotak "Gambar sampul" -> klik -> pilih JPG dari
     komputer -> beberapa detik kemudian pratinjau sampul muncul, dan
     di Cloudinary (Media Library -> folder blog) file-nya ada.
  3) Di kotak tulisan: seret satu gambar -> teks ![...](https://res.cloudinary
     .com/...) muncul otomatis.
  Kalau muncul pesan "Unggah langsung belum aktif", berarti variabel
  Cloudinary belum terbaca -> ulangi LANGKAH 2 lalu Redeploy.

CATATAN KEAMANAN
- API Secret hanya dipakai di server (Vercel) untuk membuat tanda tangan
  unggah; tidak pernah dikirim ke browser. Tanda tangan hanya diberikan ke
  admin yang sudah login.
- Semua unggahan masuk folder "blog/" di Cloudinary dengan nama file otomatis
  (nama-asli + 6 karakter acak) agar tidak saling timpa.
