INVISUAL — paket update #23 (PERBAIKAN build Vercel: FAQ tanpa @dnd-kit)

MASALAH
- Build Vercel gagal: "Module not found: Can't resolve '@dnd-kit/core'"
  (juga /sortable dan /utilities). Penyebab: paket @dnd-kit tidak tercatat
  di package.json yang ada di GitHub, jadi Vercel tidak bisa menemukannya.

PERBAIKAN (paket ini)
- Halaman /admin/faq dikembalikan ke versi TANPA library:
  urut memakai tombol panah naik/turun (seperti sebelumnya). Fitur lain tetap:
  tambah, edit di tempat, hapus, pencarian, toast, konfirmasi.
- Tidak ada lagi ketergantungan @dnd-kit -> build Vercel akan lolos.

CARA PASANG & DEPLOY:
  unzip -o invisual-update-23.zip
  rm -rf .next && npm run dev        (untuk cek lokal, opsional)
  lalu commit & push ke GitHub. Vercel akan build ulang dan berhasil.

- Tanpa npm install. Tanpa perubahan database.

--- OPSIONAL: kalau tetap mau drag-and-drop nanti ---
Jalankan di folder proyek (SEKALI), lalu commit package.json + package-lock.json:
  npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
Pastikan file package.json DAN package-lock.json ikut ter-commit & ter-push,
supaya Vercel ikut memasang paketnya. Baru pasang kembali versi drag-and-drop.
